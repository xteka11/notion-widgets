Política de privacidad

Classroom Notion Sync · última actualización: 9 de octubre de 2026

Qué datos se leen

Con permisos de solo lectura de Google Classroom, la herramienta lee la lista de cursos en los que estás matriculado, las tareas publicadas en ellos y el estado de tus propias entregas (entregada o no, y la nota cuando la devuelven).

Para qué se usan

Únicamente para crear o actualizar esas tareas en tu propio espacio de Notion. No se usan para publicidad, ni para entrenar modelos de IA, ni para ningún otro fin.

Dónde se guardan

La herramienta se ejecuta en tu ordenador. El token de acceso de Google se guarda solo en ese ordenador y las tareas solo se envían a la API de Notion, a tu espacio. No hay ningún servidor intermedio y los datos no se comparten con terceros ni se venden.

Uso de datos de Google

El uso y la transferencia de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

Puedes revocarlo cuando quieras en myaccount.google.com/connections. Las tareas ya copiadas a Notion se pueden borrar desde Notion.
